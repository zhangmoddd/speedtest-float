# 测速浮光

把「网络测速球」和「浮光」合成一个东西：**球是原版测速球（一个字节没改），右键菜单里多一项「打开浮光面板」。**

## 怎么用

双击 **`网络测速球.exe`**，屏幕右侧出现球。

| 操作 | 效果 |
|---|---|
| **左键单击球** | 打开网络详情（CPU / 内存 / 磁盘 / 实时曲线 / 今日本月流量），右上角 ✕ 可关闭 |
| **右键球** | 完整菜单 —— **第一项就是「打开浮光面板」**，下面是原版的全部菜单 |
| 按住拖动 | 移动位置，拖到边缘会吸附收起 |
| 拖到发射台 | 火箭发射动画 |
| 双击球 | 置顶 |
| 托盘图标 | 同一套菜单 |

右键菜单里的「打开浮光面板」会调起 `浮光面板.exe`，弹出浮光的五个页签
（笔记 / 计时 / 备忘 / 链接 / 设置）。**再点一次不会开出第二个面板** ——
它会叫已经开着的那个把窗口显示出来。

## 为什么是两个 exe

原版测速球是 **C# WinForms**（GDI+ 手绘，187 KB 一个文件），浮光是 **Tauri**
（Rust + React，41,000 行，61 个后端接口）。

想把浮光的五个页签搬进 C#，等于用 C# 重写 61 个接口（图片导入、图标提取、
快捷方式解析、全局热键、定时器调度……），几周工作量，而且必然掉功能。

反过来，把测速球搬进 Tauri 也一样：球的网络详情面板、流量统计窗口、
发射台动画、贴边收起全是 GDI+ 画的，重写一遍同样是几周，而且细节永远差一点。

**所以球用原版程序，浮光只提供面板，两者靠一个命名事件通信。**
从用户角度看只有一个球，右键就能看到浮光。

## 代码结构

```

├── NetSpeedBall.cs    ① 菜单加「打开浮光面板」② 加启动浮光的逻辑 ③ 空转
└── build.ps1          用系统自带 csc.exe 编译，产出 dist/NetSpeedBall.exe

app/               浮光（原版 Tauri，只加了两处）
├── src-tauri/src/panel_signal.rs   新增：单实例 + 「显示面板」信号
└── src-tauri/src/lib.rs            setup 里默认不建球、不建托盘

```

## 对原版做的全部改动

**测速球（`ball/NetSpeedBall.cs`）**

1. 右键菜单最上面加一项「打开浮光面板」+ 分隔线
2. `OnOpenFuguang()` / `LocateFuguangPanel()` —— 启动或唤醒浮光面板
3. **网络详情窗口右上角加了关闭按钮（✕）** —— 原版这个窗口是无边框的、
   没有系统关闭按钮，一旦「显示悬浮球」被关掉，屏幕上就会留下一个关不掉的浮窗。
   现在鼠标移上去有悬停反馈，点一下就关。
4. **隐藏悬浮球时一并收起详情窗口** —— 详情是挂在球上的附属窗口，
   球没了它就再没有主人。
5. `GetRocketOrbitSpeed()` 加了一个 14°/s 的空转底座，并给空转配了一簇小火苗 ——
   **原版在 0 流量时火箭完全静止、也不喷火**，这里按需求改成慢速空转 + 小火。
   小火（0.10）和真下载时的长尾焰区分得开，所以「火很大」依然能反推出「在传数据」。
6. **火箭沿外圈整圈顺时针运动**，轨道半径 0.37 → 0.432 ——
   不再用上半圈往返扫动，消除回程逆时针的问题；火箭、尾焰、发射台和发射动画也已重画。
7. **三行文字整体上移 5px**，给下方的火箭让位；顺带让数字行落到更宽的弦上，
   长数字不会被圆边切掉。
8. **活跃度弧重画** —— 原来从 126°（右下）起画一条 2.3px 的弧、半径还比光环小 2px，
   看起来像光环内壁蹭了一道划痕。现在从 12 点方向起、半径与光环一致、加粗到 3.2px，
   形成「光环被填满」的仪表盘效果。

**浮光（`app/`）**

1. 新增 `panel_signal.rs`：命名事件 `Local\FuguangShowPanel`，单实例
2. `lib.rs`：默认只开面板（`--with-ball` 可恢复带球的独立模式）

## 自己编译

**测速球**（只需要 Windows 自带的 .NET Framework 编译器）：

```powershell
cd ball
powershell -ExecutionPolicy Bypass -File .\build.ps1
# 产出 ball/dist/NetSpeedBall.exe
```

**浮光面板**（需要 Node.js 22+、Rust 1.77+、VS2022）：

```bash
cd app
npm install
npx tauri build --no-bundle
# 产出 <CARGO_TARGET_DIR>/release/fuguang.exe
```

> Rust 编译缓存能涨到 7 GB 以上。磁盘紧张就把它挪走：
> `export CARGO_TARGET_DIR=E:/cargo-target-fuguang`

两个 exe 放进同一个文件夹，`浮光面板.exe` 改名成这个名字（球按这个名字找它）。
