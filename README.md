# 测速浮光

一个悬浮球，加一套笔记面板。

球是原版「网络测速球」，改了几处顺手的地方，右键菜单上加了一项「打开浮光面板」。面板是另一套程序（浮光），管笔记、计时、备忘、链接、设置五个页签。

## 下载

**⬇ [下载最新版](https://github.com/zhangmoddd/speedtest-float/releases/latest)**

文件名是 `speedtest-float-vX.Y.Z-win64.zip`，两兆出头。也可以在 [Releases](../../releases) 页面自己挑版本。

解压完双击 `网络测速球.exe` 就能用。不用安装，放哪个文件夹都行，不想要了直接删。

解压时把整个文件夹一起解出来，别只挑那个 exe。浮光面板在「面板」子文件夹里，少了它球能开，面板打不开。

只支持 Windows 10 / 11 的 64 位版。第一次运行多半会弹「已保护你的电脑」，点「更多信息」，再点「仍要运行」。没买代码签名证书，一年一两百美金起，个人项目不值当。

## 怎么用

双击 `网络测速球.exe`，屏幕右边出现球。

| 操作 | 效果 |
|---|---|
| 左键单击 | 打开网络详情：CPU、内存、磁盘、实时曲线、今日本月流量 |
| 右键 | 完整菜单，第一项就是「打开浮光面板」 |
| 按住拖动 | 挪位置，拖到屏幕边缘会自动吸附收起 |
| 拖到发射台 | 火箭发射动画 |
| 双击 | 置顶 |
| 托盘图标 | 同一套菜单 |

点「打开浮光面板」会调起 `浮光面板.exe`。再点一次不会开出第二个窗口，只是把已经开着的那个叫到前面来。

开机启动统一由球管，启动项名字叫「测速浮光」。浮光的设置页不再单独写启动项，否则开机会同时起来两个进程。

两个 exe 分别是什么、怎么编译，写在 [知识科普-代码与程序.md](知识科普-代码与程序.md) 里。

## 为什么是两个 exe

原版测速球是 C# WinForms 写的，GDI+ 手绘，一个 187 KB 的文件。浮光是 Tauri，Rust 加 React，四万多行，后端 61 个接口。

把浮光的五个页签搬进 C#，等于用 C# 重写那 61 个接口。图片导入、图标提取、快捷方式解析、全局热键、定时器调度都得来一遍，几周工作量，功能还要缩水。

反过来也一样。球的网络详情、流量统计、发射台动画、贴边收起全是 GDI+ 画的，搬进 Tauri 同样是几周，而且细节永远差一点。

所以球保持原样，浮光只负责面板，两边靠一个命名事件通信。用户这里看到的就是一个球。

## 代码结构

```
ball/              测速球（原版 C#，只动了三处）
├── NetSpeedBall.cs    菜单加一项、启动浮光的逻辑、空转
└── build.ps1          用系统自带的 csc.exe 编译，产出 dist/NetSpeedBall.exe

app/               浮光（原版 Tauri，只动了两处）
├── src-tauri/src/panel_signal.rs   新增：单实例 + 「显示面板」信号
└── src-tauri/src/lib.rs            setup 里默认不建球、不建托盘

reference/         两个原始项目，只读，一个字没改
```

## 对原版做的全部改动

**测速球**（`ball/NetSpeedBall.cs`）

1. 右键菜单最上面加「打开浮光面板」，下面跟一条分隔线
2. `OnOpenFuguang()` / `LocateFuguangPanel()`，负责启动或者唤醒面板
3. 网络详情窗口右上角加了关闭按钮（✕）。原版这个窗口是无边框的，也没有系统关闭按钮，一旦「显示悬浮球」被关掉，屏幕上就留下一个关不掉的浮窗。现在鼠标移上去有反馈，点一下就关
4. 隐藏悬浮球时一并收起详情窗口。详情是挂在球上的附属窗口，球没了它就没有主人
5. `GetRocketOrbitSpeed()` 加了 14°/s 的空转底座，配一簇小火苗。原版在 0 流量时火箭完全静止也不喷火，现在会慢慢转。小火（0.10）和真下载时的长尾焰区分得开，所以「火很大」仍然能反推出「在传数据」
6. 火箭改成沿外圈整圈顺时针运动，轨道半径从 0.37 调到 0.432。原来沿上半圈来回扫，回程是逆时针的，看着别扭
7. 三行文字整体上移 5px，给下面的火箭让位。顺带让数字落到更宽的弦上，长数字不会被圆边切掉
8. 活跃度弧重画。原来从 126°（右下）起画一条 2.3px 的弧，半径还比光环小 2px，看起来像光环内壁蹭了一道划痕。现在从 12 点方向起，半径跟光环一致，加粗到 3.2px，成了「光环被填满」的仪表盘
9. 流量统计窗口整个重画：顶部的原生按钮换成自绘的分段控件，日期改成点开日历选，四张统计卡片统一配色，柱状图改成堆叠并限制柱宽，排行列表重排了列宽和行高

**浮光**（`app/`）

1. 新增 `panel_signal.rs`，命名事件 `Local\FuguangShowPanel`，单实例
2. `lib.rs` 默认只开面板（加 `--with-ball` 可以恢复带球的独立模式）

## 自己编译

测速球只要 Windows 自带的 .NET Framework 编译器：

```powershell
cd ball
powershell -ExecutionPolicy Bypass -File .\build.ps1
# 产出 ball/dist/NetSpeedBall.exe
```

浮光需要 Node.js 22+、Rust 1.77+、VS2022：

```bash
cd app
npm install
npx tauri build --no-bundle
# 产出 <CARGO_TARGET_DIR>/release/fuguang.exe
```

Rust 的编译缓存能涨到 7 GB 以上。磁盘紧张就把它挪走：`export CARGO_TARGET_DIR=E:/cargo-target-fuguang`

最后把两个 exe 放进同一个文件夹，`fuguang.exe` 改名成 `浮光面板.exe`，球按这个名字找它。
