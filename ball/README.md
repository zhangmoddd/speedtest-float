# 网络测速球

一个轻量 Windows 网络测速小工具。它用原生 WinForms 编写，不依赖 Electron，构建后是单个 `NetSpeedBall.exe`。

## 功能

- 悬浮测速球实时显示下载和上传速度
- 单击悬浮球可查看 CPU、内存、每块物理磁盘的实时活动率及网络详情（插拔 U 盘自动增减）
- 详情面板显示今日/本月下载与上传流量，重启不清零，只有过了 00:00 才算新的一天
- 流量统计窗口：按天/月/年或任意日期范围查看总流量与日均流量，附每日流量柱状图和应用流量排行榜（排行榜需要管理员权限，见下）
- 白色仪表盘悬浮球带云层和小火箭，火箭转速由真实下载速率决定：**没有流量（或低于 8 KB/s 的后台心跳）时完全静止**，下载越快转得越快，速度超过 500KB/s 时显示尾焰
- 按住悬浮球会出现发射台，拖入后松手可触发纯动画火箭发射互动
- 系统托盘常驻，右键可以显示/隐藏悬浮球、切换置顶、切换开机自启动、退出
- 右键菜单可直接打开 Windows 任务管理器
- 鼠标左键拖动悬浮球，松开后自动保持在屏幕工作区内
- 拖到屏幕边缘松开可贴边收起，鼠标移入后自动展开
- 双击悬浮球可把它提到窗口最前面
- 使用当前用户注册表启动项实现开机自启动，不需要管理员权限
- 已声明系统级 DPI 感知，高分屏（125%/150% 缩放）下悬浮球与文字渲染清晰

## 流量统计说明

- 总流量（今日/本月/日均/柱状图）：按网卡层真实字节增量统计，含所有协议
- 应用排行榜：通过每条 TCP 连接的字节计数器归因到进程（与资源监视器同机制）。
  **这个功能需要管理员权限**：Windows 只允许管理员开启逐连接的字节采集，普通权限下系统会直接拒绝，排行榜会一直是空的。
  需要时右键托盘图标选“以管理员身份重启”即可；不想提权也不影响其他功能。
  另外它不含 UDP/QUIC 流量与协议头开销，因此各项之和略小于总流量
- VPN/代理：检测到隧道类网卡（TUN/PPP，含 WireGuard）在线时只统计隧道流量，避免与物理网卡重复计数
- 数据保存：`%LOCALAPPDATA%\NetSpeedBall` 下两个小文件（归档 + 增量日志），重度使用一年不足 1 MB；每 60 秒落盘一次，退出时归档，重置今日流量只在托盘菜单触发

## 开机就是管理员权限

右键菜单里的「开机自启动」勾上之后：

- 当前已是管理员：直接注册计划任务「测速浮光」（登录时以最高权限启动，**不弹 UAC**），
  同时删掉旧的注册表启动项，避免启动两次
- 当前是普通权限：弹一次询问，选「是」就以管理员身份重启，新实例把任务注册好；
  选「否」还是用普通权限开机启动（应用流量排行没有数据）
- 取消勾选：计划任务和注册表启动项一起删掉

原理：计划任务勾了「使用最高权限运行」后，任务计划程序直接用完整令牌拉起进程，
不走 shell 的 UAC 流程。注册这种任务本身需要管理员，所以第一次必须提权一次。

## 详情面板上的资源数字和曲线

- **CPU / 内存 / 磁盘** 都是「当前这一秒」的瞬时值：
  - CPU 取两次采样之间的系统时间差（内核 + 用户态，扣掉空闲），和任务管理器同源
  - 内存取 Windows 的「已用 / 物理内存总量」。待机缓存算作可用，所以这个数会低于任务管理器里「已提交」那一行
  - 磁盘按**物理磁盘**逐块列一行（`磁盘 0（C: D:）` / `磁盘 1（E:）`），数值是**活动时间**
    （100 − 空闲时间），口径就是任务管理器「磁盘」那一列，不是空间占用
- **磁盘列表自动增删**：每 5 秒重扫一次系统里的 PhysicalDisk 实例，
  插上 U 盘最多 5 秒后就多出对应的一行并开始显示活动率，拔掉自动消失；面板高度跟着变
- **数字带死区**：速率、CPU/内存/磁盘这些数字每秒最多只更新一次，而且新采样和当前值
  差得不够多（速率 25%、CPU 12%、内存 6%、磁盘 20%）就**完全不改** ——
  空闲时那点几十 KB 的抖动不会让数字乱蹦。
  进度条和火箭仍然按帧平滑过渡，所以"在传数据"依然看得出来
- **60 秒曲线是线性刻度**，比例尺取这 60 秒的最高值，地板 512 KB/s：
  日常 20~50 KB/s 的零碎流量贴着底边走，真有大下载时才顶上去。
  曲线画之前做了一次三点平滑，避免采样抖动变成锯齿。
  准确数值看上面两行（当前速率）和曲线右上角（这 60 秒的峰值）
- 自检：`NetSpeedBall.exe --render-details 路径.png` 把面板渲染成图片，
  `--render-preview 路径.png` 渲染悬浮球本体，都不用真的把面板弹出来

## 构建

在 PowerShell 中运行：

```powershell
.\build.ps1
```

生成文件：

```text
dist\NetSpeedBall.exe
```

## 使用

直接运行 `dist\NetSpeedBall.exe`。托盘图标右键菜单里可以开启“开机自启动”、打开“流量统计”，也可以随时退出。

想让“应用流量排行”有数据，右键托盘图标选“以管理员身份重启”。普通权限下排行榜是空白的（软件会直接写明原因），其余功能都正常。

## 轻量说明

程序按实际计数器增量计算当前流量速率，并使用短时间平滑减少单秒抖动。统计优先选择带默认网关的物理网卡（VPN 隧道在线时改为只统计隧道），避免代理、VPN 或虚拟网卡把同一流量重复计算；程序没有后台网络请求、没有测速服务器探测，也不会主动制造流量，因此显示的是当前实际网络活动，不是线路带宽上限。

## 火箭转速说明

火箭的转速完全由下载速率驱动，没有任何"空闲也转"的底座转速：

- 下载低于 8 KB/s（系统心跳、NTP 校时、推送保活这类噪声）按空闲处理，火箭停在原地、尾焰熄灭
- 8 KB/s 以上开始转动，8 MB/s 达到最高转速。刻度是对数的：24 KB/s 约 17°/s（20 秒一圈），1 MB/s 约 104°/s（3.5 秒一圈），8 MB/s 及以上 156°/s（2.3 秒一圈）
- 流量停止后约 0.7 秒内平滑减速到完全静止，所以"火箭在转"可以反推"确实在下载"

注意这跟任务管理器的"网络"列不是同一个口径：任务管理器显示的是**链路利用率**（占网卡带宽的百分比），几 KB/s 的流量在千兆网卡上永远是 0%；悬浮球显示的是**真实字节速率**。
